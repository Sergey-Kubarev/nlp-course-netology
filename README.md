# NLP Course — Learning Notebook Archive

Educational notebooks exploring classic natural-language processing methods. **These are course exercises and experiments, not a production NLP service.**

## Areas covered

- **Text classification and sentiment:** `2_classification.ipynb`, `4_sentiment.ipynb`, and related exercises
- **Named entity recognition:** `2_RussianNER.ipynb`, `5_NER.ipynb`
- **Topic modeling:** `3_TopicModelling.ipynb` and homework notebooks
- **Language models and syntax:** `5_LM.ipynb`, `2_syntax.ipynb`
- **Word representations and neural networks:** `4_WMD.ipynb`, `4_RU_FNN.ipynb`, `4_RU_FNN_CNN.ipynb`

## Using the archive

Browse notebooks directly on GitHub. Individual exercises may require datasets, historical package versions, or additional setup and are not guaranteed to run unchanged in a modern environment.
